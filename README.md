# JW Data Consulting · site para escolas

Site estático em Astro + GSAP. Versão de teste publicada em https://jwdataconsulting.com.br/jw-escolas/ (sem indexação).

- Ver localmente: `npm install` e `npx astro dev`
- Publicação: `npx astro build`, depois enviar a pasta `dist` para o ramo `gh-pages`

Todas as telas do site são ilustrativas, com dados fictícios.
